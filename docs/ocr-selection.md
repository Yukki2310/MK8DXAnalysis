# 名前の文字認識エンジンの選定（精度優先）

2026-11-18、インストール容量を問わず精度を優先する前提で再選定した。

## 評価データ

ラウンジ動画（YouTube 1080p60）の4区間から、リザルト画面の名前行を切り出して作った。

- 正解が分かっている2レースの行を基準にして、他の全フレームの行を**画像照合（identity.py）で自動ラベル付け**した
  （基準との距離が小さく、他の選手との差が十分ある行だけを採用）。
- 選手ごとに最大20枚、時間的に散らして選び、合計 **220枚**。背景・圧縮ノイズ・明るさが異なる実際の画面。
- 名前は11種類（`kı c.qq` `RS★` `ranger #1/#2` `A★ぜんいちろう` `Kb◇ねぇあまぁ♭` `A      A` など。
  ラテン文字・かな・記号・紛らわしい `#1`/`#2` を含む）。
- 注意: 名前の種類は少ない。実際のラウンジには多様な名前があるので、絶対値は目安として見る。

指標:

- **緩い一致**: 空白・大文字小文字・`ı/l/1/I` の違いや小さいかな・`♭` を無視した完全一致
  （チーム判定や選手の見分けに必要な水準）。
- **厳密一致**: 空白だけを無視した完全一致（大文字小文字・記号も一致）。表示名としての正しさ。

## 結果

|---|---|---|---|---|
| **Qwen3-VL-4B**（GPU, bf16） | 211/220 | **196/220** | **0.052** | 12枚まとめて1.3秒（VRAM 約9GB） |
| Qwen3-VL-2B（GPU, bf16） | **216/220** | 186/220 | 0.066 | 同程度（VRAM 約5GB） |
| Qwen2.5-VL-3B（GPU） | 200/220 | 149/220 | 0.121 | |
| PP-OCRv5 mobile（ONNX） | 191/220 | 158/220 | 0.108 | 1枚10ms（CPUで可） |
| PP-OCRv5 server（ONNX） | 141/220 | 117/220 | 0.217 | 1枚0.5秒 |
| manga-ocr | 56/220 | 48/220 | 0.337 | |
| EasyOCR（ja+en） | 41/220 | 40/220 | 0.276 | |

（Windows 標準OCR・PP-OCRv4 日本語は最初の24行の予備評価で 16/24・9/24。PaddleOCR 本体は環境で動作せず除外。）

## 読み取れなかったもの

- Qwen3-VL-4B: `Xb` をキリル文字の `Хб`（見た目が同じ別の文字）で返すことがある → 後処理でラテン文字へ置き換える。
  `♭` は `b`/`ｂ` になる（全角は半角へ）。それ以外はほぼ完全。
- PP-OCRv5 mobile: `◇` `♭` などの記号を落とす、`A      A` を `AAL` と読む、背景次第で `Xb` を `xb` と読む。
- EasyOCR・manga-ocr は、このゲームのフォントと背景では実用にならない。

## 採用

1. **Qwen3-VL-4B-Instruct**（NVIDIA GPU の空きメモリ約10.5GB以上）— 厳密一致が最良で、記号まで読める。
2. **Qwen3-VL-2B-Instruct**（空き約5.5GB以上）— 4B に迫る精度で、メモリが足りないとき用。
3. **PP-OCRv5 mobile**（GPU なし）— CPU だけで動く軽量版。

`textrec.create_recognizer` が上から順に試して、使えるものを選ぶ。環境変数 `MK8DX_OCR=rapid` で軽量版を強制できる。
モデルは配布物に同梱する（`tools/fetch_models.py` で `assets/models/` に取得。VLM は計約12GB）。
VLM は精度が高いので、選手ごとに最初の1回だけ読む（軽量版は3回の多数決）。12人分は1回のバッチで読む。

## 視覚言語モデルの追加活用: チームの推定（2026-11-18）

名前を読むだけでなく、Qwen3-VL-4B に名前画像12枚を見せて「同じタグで始まる選手を組にして、タグを答える」
実験をした（文字認識の結果は渡さない）。正解が分かっている2レースの画面で、**どちらも6チームすべて正解**、
タグも `xi` `FR` `ranger` `Xb` `RR` `A` と妥当だった（約10〜12秒）。チーム2人の画像から共通タグだけを読ませる
方法も、6チーム中5チームで正解（残る1つは `A` を名前全体で返した）。

そこで、決定的な方法（名前の先頭の画像照合 → 文字認識の読みからの推定）で決められないときの最後の手段として、
この推定を使う。答えは「12人が重複なく、決まった人数ずつ」の検証を通ったものだけ採用する。
常に呼ぶと1レースあたり約12秒かかるので、フォールバックに限る。
