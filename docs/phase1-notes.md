# フェーズ1 メモ（画像ベース識別）

実装: `src/mk8dx/identity.py`、確認CLI: `tools/identity_check.py`、テスト: `tests/test_identity.py`（合成画像）。
実フレームは `test_data/`（動画）→ `tools/extract_frames.py` で `fixtures/frames/` に抽出（どちらも .gitignore）。

## 実測（2026-11-18、ラウンジ動画のレース3 vs レース4）

- 通常行の同一人物は距離 0.01〜0.10、別人は 0.6 以上。
- 自分の行（黄色ハイライト）は文字が**暗い灰色の黄色地**で極性が逆。min チャンネルの白文字抽出では
  ほぼ空になる。ハイライト行判定（G・R の平均 > 110）で暗文字抽出に切り替えて解決。
- 行ごとに縦位置がずれる（累計画面の並べ替え中など）。±6px の平行移動だけでは足りないので、
  文字の外接矩形で切り出してから比較する。
- 国旗は名前領域の右側にあり、文字として混入するため x<365 に限定。
- 未解決: 'ranger #1' と '#2' のような酷似ペアは距離差が小さい（正解 0.02 に対し他方 0.21）。
  レース4の12位 → 'ranger' 系は 0.21 / 次点 0.33 で曖昧（'#2' が不在か '#7' かは要ラベル確認）。
  SAME_THRESHOLD=0.12 は暫定値。正解ラベル作成後にベンチで再校正する。

## 追記: roster 統合と実フレーム検証（2026-11-18）

- `Observation.mask` / `RosterEntry.masks`（最大4見本、永続化あり）を追加し、`Roster.resolve` は
  マスクがあれば画像距離×10 を主コスト、OCR名は同点時の微調整(0.03倍)にした。マスクが無い観測・
  エントリは従来の名前コストにフォールバックする（既存テストは無改修で通る）。
  重複統合も、両方にマスクがあれば画像距離だけで判定する。名前が読めない新規は「選手N」で仮登録。
- **ROI の行ピッチが誤っていた**: 設定は76pxだが実画面は78px（1位y=74、12位y=932）。下位行の文字が
  切れ、名前OCRの誤りにも影響していた可能性が高い。`config/roi_1080p.json` を修正（OCR再評価が必要）。
- 行の上下端に接する欠片（区切り線など）が外接矩形を広げて距離が悪化していたため、
  `identity._remove_noise` で除去。
- `tools/step8_check.py`（OCRなし）の結果: レース1→3→4で、レース4の12名はすべて既存エントリに
  割り当てられ、新規の誤登録なし。レース3の新規3名（入れ替わり）も妥当。処理時間は 30〜55ms/フレーム。
- 未検証: 正解ラベルが無いので「正しい人に割り当てたか」の厳密な数値評価は未実施
  （上の数字は一貫性と目視確認）。'ranger #1' / '#2' 型の酷似ペアは距離差が0.2程度で最も弱い。

## 追記: 実機映像で見つかった不具合と対応（2026-11-18）

- **黄土色・白っぽい背景の行でマスクが壊れた**: 極性（白文字／暗文字）を行の平均輝度で決めていたため、
  明るい背景の通常行が「自分の行（黄色バー）」と誤判定され、暗文字用の抽出で崩れていた。
  両方の抽出をして「面積が大きく成分が少ない」方を採用する方式に変更（`identity.extract_name_mask`）。
- 文字の明るさが映像ごとに違う（ぼけ・圧縮）ため、白文字抽出は固定しきい値をやめ、行の文字の
  ピークに合わせたヒステリシス二値化にした。
- 文字の帯から外れた欠片や背景の細い横線が外接矩形を広げて距離が悪化していたため除去。
- 管理画面は文字マスクではなく**名前行の実画像**を表示する（マスクは欠けて読みにくかった）。
- 文字認識を Windows OCR から PP-OCRv5 認識モデル（ONNX）へ変更。24行で完全一致 16→22。
- リザルト画面は `data/screenshots/<セッション>/raceNN.jpg` に保存する（読み取りの確認・不具合報告用）。
