## 名前OCRの改善（今回の実装変更）

1. **断片の結合**: PaddleOCR は名前を複数断片で返すことがある。従来は
最大信頼度の断片だけを採用していたため名前の前後が欠けていた。
x座標順に結合するよう変更（ocr.py `_run`）。
2. **名前ROI拡大**: x=1058 開始ではタグ部分が欠ける（'クッパ'->'ッパ' 等）。
x=1015 開始に拡大（config/roi_1080p.json）。
3. **日英デュアルエンジン**: japan モデルはラテン名が苦手
（'Xb'->'メロ', 'F'->'E'）。en モデルは 'racist #1' 'FR Flowx' を正確に
読むが日本語名は読めない。名前ごとに候補選択（choose_name_candidate:
ひらがな・漢字を含む候補を優先、それ以外は信頼度で選択）。
4. **累計数字の専用リーダー**: en モデル＋拡大＋二値化（Otsu/反転）の
多数決（recognize_total）。japan 素読みではほぼ読めなかった累計列が
読めるようになった（例: フェーズBで 46,41,39,... を取得）。
5. **順位数字**: en モデル＋拡大（recognize_digits_en）。japan は
'1'->'-' 等の誤読が多く、順位列検証に使えなかった。

正規化しての一致率（目視確認した正解との比較）: レース1 A 5/12、
レース3 A 8/12。残る誤りは系統的:
- 記号の欠落・化け: '★'->欠落/'大'/'か'、'◆'->欠落、'◇'->欠落
- 'ẇ' を含む名前は頭のトークンが落ちる（'ẇf ths'->'ths'）
- ハイライト行（黄色・自プレイヤー行）の 'RR★' が '日日-' 等に化ける
- '#1' と '#7' の混同（レースにより揺れる）
- 同一人物の読みはレース間でよく似る（'xi c.qq'/'XI c.qq'/'xI c.qq' 等）
→ レース横断の多数決＋編集距離での名寄せが有効な見込み。

## フェーズ判別で分かったこと

- フェーズAには「+N 表示＋累計カウントアップ」→「+ が消えて累計だけ残る」
の2形態がある。後者はフェーズBと見た目が同じで、1枚では区別できない
場合がある（classify_plain_phase: 累計のパターンで推定し、
決められなければ unknown）。
- カウントアップ途中ではスコア列に残量（'+5' 等）が表示される。
集計に使うフレームはアニメーション完了後の安定フレームに限るべき。
- フェーズBは行の並び替えアニメーションがあり、途中フレームでは
順位数字が重複表示される（'5' が2行等）。順位列検証は両端の行
（1・2・11・12位）を使うことで回避した。
- エッジ密度だけの判別は、半透明パネルに明るい背景が透けると誤判定する
（フェーズBを race_result と誤判定した実例あり）。密度は補助信号に格下げし、
'+' の有無と配点の読み取りを主信号にした。
- 圧縮動画では '+' が 'ト'/'十' に化ける。スコア列に限っては
先頭の 'ト'/'十' を '+' とみなす（parse_points_text）。
- 1レース目にフェーズBが映らない（ユーザー指摘）: 状態遷移はフェーズBを
必須にしない。照合は「来たときだけ」行う。

## クラスタリング検証

- 目視で確定したレース3の12名（正規名）では **2v2 の割り当てが正しく成立**:
{xı: c.qq, avalon} / {FR: FR, Flowx} / {racist: #1, #2} /
{Xb: Xb, Xb◇ねえあまぁƄ} / {RR★: 2名（同名・国旗違い）} /
{A: A★ぜんだかいとしき, A A}。クラスタリングロジック自体は正しい。
- 生OCRのままでは全レースで不成立。素朴な最近傍の名寄せも失敗する:
'RR'（★欠落）は 'FR' と 'RR★' の両方に距離1でタイになり誤選択する、
化けた短い名前は最短の正規名 'FR' に吸着する。
→ 名寄せは「選手名簿全体への一括割り当て（各正規名の使用回数を制約に
した全体最適化）」＋国旗列の併用で設計する必要がある（次ステップ）。
- 同名プレイヤーが実在する（'RR★' が2名、国旗で区別可能）。
選手名簿のキーは名前だけでなく国旗も含めるべき。
- レース1の12名は正規名でも 2v2 割り当てが成立しなかった
（Rev◆、ẇf ths がどのタグとも組にならない）。ユーザー確認済み
（2026-11-18）: レース1は人数が揃っていなかったためで、この判断で正しい。
また 'ẇf ths' では分音記号代用の検知
（has_forbidden_diacritic）が実データで正しく発火した。
- 選手名簿はレース間で入れ替わる（レース1の Rev◆・ẇf ths が消え、
FR Flowx・A A・RR★（ベルギー）がレース3までに加入）。
名寄せは「同一イベント内でも変動しうる」前提で設計する。

## 静止判定について

リザルト表示中も背景のキャラクターアニメーションが動くため、
全画面のフレーム間差分では静止を取れない。静止判定はパネル領域に
限定すべき（detector.py の StillnessJudge は今後パネルcropで使う）。
