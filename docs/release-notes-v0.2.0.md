## MK8DX 自動集計 v0.2.0

マリオカート8 デラックスのリザルト画面をOBSの仮想カメラから自動で読み取り、チームごとの得点を集計して、
OBS のオーバーレイと管理画面に出す Windows アプリです。

### できること
- リザルト画面を自動で検知して、12人の順位から得点（15・12・10…1）を集計する。
- 画面の名前から同じ選手を識別し（画像の照合）、名前は視覚言語モデル **Qwen3-VL**（GPU）で読み取る。
  同じチームの選手は、名前の先頭（タグ）から自動で組にする。
- 管理画面は 1 画面のダッシュボード。選手名・チーム名はその場で直せて、順位に即反映される。
- オーバーレイは普段は小さな順位表を表示し、リザルト画面の間だけ大きな順位表が展開する（1〜3位は金銀銅）。
- アプリを閉じても、次に開くと直前の試合が続けられる。

### 動作環境
- Windows 10 / 11（64bit）、OBS Studio の仮想カメラ（1920×1080 推奨）
- **NVIDIA GPU（空きメモリ 約10.5GB 以上）があると、高精度な文字認識（Qwen3-VL-4B）を使います。**
  足りない場合は小型モデル（インストール時に追加を選択）か、GPU なしで動く PP-OCRv5 に自動で切り替わります。

### インストール方法
1. 下の **9 個のファイルをすべて**同じフォルダにダウンロードする
   （`MK8DXAnalysis-Setup.exe` と `MK8DXAnalysis-Setup-1.bin` 〜 `-8.bin`、合計約 15GB）。
2. `MK8DXAnalysis-Setup.exe` を実行する（標準インストールで約 13GB、数分かかります）。
3. 起動するとブラウザで管理画面が開きます。タスクトレイのアイコンから「管理画面を開く」「終了」ができます。

### 注意
- 実行ファイルは署名していないため、初回に Windows の SmartScreen が警告を出すことがあります。
  PyInstaller で作っているため、ウイルス対策ソフトに誤検知される場合があります。
- 開発中の検証は、YouTube のラウンジ動画を使って行いました。**実機（Switch ＋ OBS 仮想カメラ）での通しの確認は十分ではありません。**
  うまく読み取れない画面があれば、`%APPDATA%\MK8DXAnalysis\screenshots` に保存されるリザルト画像を添えて Issue でお知らせください。
- 同梱するモデル・ライブラリのライセンスは `THIRD_PARTY_NOTICES.md` を参照してください。
